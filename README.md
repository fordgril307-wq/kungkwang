# 쿵쾅 — 층간소음, 감정 대신 기록으로

휴대폰으로 녹음한 층간소음을 AI가 종류별로 가려내고, 법정 기준(공동주택 층간소음의 범위와 기준에 관한 규칙)과 비교한 뒤, 소음 일지와 이웃에게 보낼 쪽지까지 만들어 주는 웹 서비스 PoC입니다. 과기정통부 × 엘리스 AI 챌린지 출품작.

## 3단계 흐름
1. **소리 분석** — 녹음 파일 업로드 또는 마이크 30초 녹음 → 소리 종류(걷기·뛰기·망치질·가구 끌기·문·음악·말소리·가전) 분류, 1분 등가·최고소음도·5분 등가 기준 판정
2. **소음 일지** — 7일 × 24시간 히트맵, 야간 비중, 기준 초과 횟수, 이웃사이센터 상담용 일지 복사
3. **알리기** — 이웃에게 연락 / 관리사무소 사실 확인·중단 권고 / 층간소음관리위원회 조정 / 이웃사이센터 상담·측정 / 분쟁조정 신청 5가지 경로 중 골라, 경로별 안내와 함께 메시지·알림서·조정 신청서·상담 요약·분쟁 경위서를 일지로 작성

## AI 구성
- 1단: 공개 소리 인식 모델 YAMNet(521종) — MediaPipe Tasks Audio로 브라우저 안에서 실행
- 2단: 층간소음 판별 — 저음 비중, 지속시간, 반복 간격으로 바닥충격음 종류 보정
- 녹음 원본은 기기 밖으로 전송하지 않습니다. 일지는 브라우저 저장소에만 저장됩니다.

## 한계
휴대폰 마이크 측정값은 공인 측정이 아닌 참고값입니다. 법적 판정은 층간소음 이웃사이센터(1661-2642) 등의 현장 측정으로 정해집니다.
